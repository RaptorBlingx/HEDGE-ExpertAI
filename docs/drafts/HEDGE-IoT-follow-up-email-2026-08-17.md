**Subject:** HEDGE-ExpertAI — Technical Overview and App Store Integration Information Request

Dear HEDGE-IoT Team,

I hope you are well.

Please find attached a technical overview of HEDGE-ExpertAI and a list of the App Store information needed to prepare the integration phase.

The current development design includes an embeddable web widget, a gateway API, conversational processing, hybrid App discovery and ranking, metadata-grounded recommendation explanations, and catalogue ingestion with a derived search index.

The current development environment uses a synthetic catalogue and a provisional adapter contract. It is not connected to the HEDGE-IoT App Store API. We therefore do not claim App Store compatibility, sandbox validation, production deployment, or achievement of project KPIs at this stage.

To align the integration with the App Store correctly, we would appreciate your support with:

- sandbox access, suitable test accounts, and a technical contact;
- API/OpenAPI documentation, authentication requirements, request/response examples, versioning, rate limits, and error conventions;
- catalogue schema and update semantics, including identifiers, timestamps, App detail URLs, update/deletion behavior, and any webhook or event support;
- any SAREF-aligned metadata available from the App Store, including its exact representation;
- the approved widget integration method, frontend and asset-hosting requirements, CSP/CORS rules, accessibility/localization guidance, and navigation behavior;
- identity, security, logging, consent, privacy, retention, deployment, and staging requirements;
- a representative sandbox dataset and a jointly reviewed query set for later validation.

Once this information is available, we will align the adapter and widget with the official App Store contract and carry out the corresponding sandbox integration tests.
